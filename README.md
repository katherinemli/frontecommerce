# E-commerce Frontend (Quasar)

**[Français](#français) · [English](#english)**

---

## Français

Vitrine d'une petite boutique en ligne : liste de produits, panier et pages de paiement, qui consomment l'API REST [backendecommerce](https://github.com/katherinemli/backendecommerce).

### Points forts
- Catalogue de produits récupéré de l'API avec Axios
- Panier avec requêtes de produits en parallèle (`axios.all`), réductions par coupon et totaux
- Page de paiement
- Mise en page Quasar, prête pour l'i18n

### Technologies
Vue 2 · Quasar · Axios · vue-i18n

### Exécution locale
```bash
npm install
npx quasar dev
```

---

## English

Storefront for a small online shop: product listing, cart and payment pages, consuming the [backendecommerce](https://github.com/katherinemli/backendecommerce) REST API.

### Highlights
- Product catalog fetched from the API with Axios
- Cart with parallel product requests (`axios.all`), coupon discounts and totals
- Payment / checkout page
- Quasar layout, i18n-ready

### Stack
Vue 2 · Quasar · Axios · vue-i18n

### Run locally
```bash
npm install
npx quasar dev
```
